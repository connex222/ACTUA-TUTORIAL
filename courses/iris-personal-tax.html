    What IRIS Personal Tax does

    3 minutes

    In this lesson
    • The returns it prepares
    • How it links to other modules

    IRIS Personal Tax prepares Self Assessment tax returns (SA100) for individuals, works out the tax, and files the return with HMRC.

    LinkWhat it brings in
    IRIS Accounts ProductionSole trader and partnership figures for the self-employment and partnership pages
    IRIS Practice ManagementClient details, jobs and deadlines
    IRIS OpenSpaceSending the return for client approval, and receiving tax data from clients
    Desktop or cloud?

    This course follows the desktop IRIS Accountancy Suite. In IRIS Elements (cloud), the stages are the same but menus differ.

    Lesson 2 of 6

    Set-up for online filing

    4 minutes

    In this lesson
    • Agent authorisation
    • Storing your filing details
    1. Make sure the practice is authorised to act for the client with HMRC through the agent services account.
    2. Log on as a master user and open a client.
    3. Select Tax Options (next to the agent’s name and address).
    4. Enter the agent reference, HMRC user ID, password and the email address for HMRC responses.
    The “test” option

    When generating a return, the test option is only for checking the connection to HMRC during set-up. Never use it for real returns.

    Lesson 5 of 6

    Approval and filing

    5 minutes

    In this lesson
    • Getting approval
    • Generating and transmitting
    1. Send the return to the client for approval, for example through IRIS OpenSpace, and record the approval.
    2. Select Reports, then Electronic Tax Return.
    3. Choose Final as the return status and New (or Amended for an amendment), then generate.
    4. Select Reports, then Transmit Internet Return, to send it to HMRC.
    5. Check HMRC’s response and keep the submission receipt. Update the job in Practice Management.
    Never file without approval

    The client must approve the return before it’s filed. Filing an unapproved return is a serious professional risk.

    Lesson 6 of 6

    Deadlines and amendments

    3 minutes

    In this lesson
    • Key dates
    • Correcting a filed return
    DateWhat
    31 OctoberPaper return deadline
    30 DecemberOnline return, if the client wants tax under £3,000 collected through their tax code
    31 JanuaryOnline return and payment of the balance and first payment on account
    31 JulySecond payment on account

    To correct a filed return, generate an Amended electronic return. Amendments are normally possible within 12 months of the 31 January filing deadline.

      Something’s gone wrong

      Select a question to see the answer.

      HMRC rejected the return

      Read the error in the response. Common causes are a wrong UTR, a return already filed for that year (send Amended instead), or missing details.

      I can’t transmit

      Check the agent details in Tax Options and that you’re authorised for the client.

      The sole trader figures haven’t come through

      Check the accounts period in Accounts Production matches the tax year basis, and refresh the link.

      The client disagrees with a figure after approval

      Don’t file. Resolve it with the responsible accountant, update the return, and get fresh approval.
